Connection Finder

                   

                        Use breadth-first search to find the                         fewest flights between two airports.

How the Search Works

               

                    Breadth-first search visits airports one                     connection at a time. Because every flight                     counts as one step, the first route found                     uses the minimum number of flights.

About the Data and Algorithms

                   

                        Understanding how this flight network                         was constructed and analyzed.                    

               
           
           

Data Source

           

                This project uses the OpenFlights airports.dat                 and routes.dat datasets, representing a historical                 snapshot of airline routes around 2014.                 It is not a live airline schedule.            

           

Network Construction

           

                Airports are vertices and domestic routes are                 undirected edges. Duplicate routes and                 self-connections are removed. Only airports                 in the United States with valid three-letter                 IATA codes and coordinates are included.            

           

Algorithms

           
                   
  •                     Selection sort:                     Ranks airports by the number of connections.                
    •                
  •                     Haversine formula:                     Calculates great-circle distances                     between airports.                
    •                
  •                     Binary search:                     Finds airport codes efficiently                     in an alphabetically sorted list.                
    •                
  •                     Breadth-first search:                     Determines connectivity and minimum                     flight counts.                
    •                
  •                     Connected components:                     Identifies disconnected airport groups.
